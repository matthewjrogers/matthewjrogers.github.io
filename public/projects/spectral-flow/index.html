spectral-flow

Key decisions

  • Streaming architecture over batch — traded perfect accuracy for 99.7% accuracy at 1000x speed, which researchers unanimously preferred
  • Kept the Python API surface even though the core is C++ — adoption mattered more than exposing every knob
  • Built a “replay mode” so physicists could re-analyze past beam runs with new parameters — turned a one-shot experiment into an iterative one
